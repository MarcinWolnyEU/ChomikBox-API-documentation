Configuration - files, defaults and brands

  1. Overview
  2. Configuration

ChomikBox keeps its settings in INI files. Values are resolved in layers. The application defaults are the values the application supplies when it reads a key. The default config (defconf.ini) is built into the application and overrides those application defaults. A small per-brand overlay and the user's own conf.ini sit on top.

All default config values below are Observed, as are the values of the brand files. Meanings are translated from the Polish comments in the default config or taken from how the application uses the key.

Layering - how a value is resolved

  1. Application default. The value the application supplies when it reads a key (for example 15 for [network] connection-timeout). It is used only when no later layer defines the key.
  2. Default config from :/default/defconf.ini, built into the application. Its values overwrite the application defaults.
  3. Brand overlay from :/default/defconf-<domain>.ini, where <domain> is base.ini [main] domain.
  4. User value from conf.ini.

The application builds :/default/defconf-%1.ini and falls back to :/default/defconf.ini Observed. Since a brand file holds only seven keys, it must overlay the generic file rather than replace it; the exact merge order of 2 and 3 is Inferred.

Application defaults and default config values often differ. Because the default config overwrites the application defaults, the effective value is usually the default config one:

Default config - how to read it

For each key the default config lists, as comments, where the application reads the key and with which application default, followed by the key = value line itself. Hand-written Polish remarks are mixed in. Lines starting ; !!! ambiguous value mark keys that are read with different application defaults. Simplified example:

; application default: 15 (int)
connection-timeout = 20

Sections in $$…$$ are templates for names built at run time. [$$app->protoBox()->currentHamsterDataSection()$$] becomes [data-<hamsterId>] and holds per-account values such as default-folder-id and playlist-folder-id (both -1 by default). [$$_moduleName$$] holds each module window's geometry, and [$$currSect$$] holds each saved account's login, password-hash, password-len and password-remember. @DEFAULT@ means the value is computed by the application. [proto-webox] - web links and service hosts

In the web-box-*-url keys, %1 is the web address (http://DOMAIN/) derived from web-box-service-url. In that key itself %1 is the bare domain and %2 is the session token returned by Auth, so it opens the website already logged in. The values for chomikuj.pl come from the brand overlay.

The client reads %1 as the service host box.chomikuj.pl. Live, http://box.chomikuj.pl/chomik/chomikbox/LoginFromBox redirects to http://chomikuj.pl/chomik/chomikbox/LoginFromBox, which starts a web session, while both variants of the generic /box/LoginFromBox path fail. Live

The update check compares each downloaded file with the sha1 attribute of packages.xml; both arrive over plain HTTP, so it detects corruption, not tampering (C-07). The updater writes the plug-in's registry value in the 64-bit registry view and rewrites base.ini only on a clock before 2012. Observed

What password-hash is

It is the same lower-case hex MD5 that the SOAP Auth call sends as passHash, and the service accepts it in place of the password. conf.ini is also attached to crash reports. Consequences: Security, C-02.

Appearance, player, debug - selected keys

Skins and panel

  • [appearance] skin is empty by default; default-skin = green2, default-skin-ru = green, default-hintskin = simple, default-hintskin-ru = green.
  • [appearance] hide-if-fullscreen = true with fullscreen-check-period = 200 ms; baloontip-show = true, baloontip-timeout = 5 s; jpeg-quality = 85; thumb-quality = 80; thumb-size = 160×120.
  • [panel] panel-at-start = hide (show, hide or last), default-module = uploader, dockable = true, default-sticky = true, modules-always-visible = true.
  • [animation] enable = true, opacity = 100, scale = 1.0, transparent = false, mirror-flip = false.

Player (Muzyka)

  • Media-key shortcuts Media Play, Media Stop, Media Next, Media Previous enabled; Volume Up, Volume Down, Volume Mute disabled; global-shortcuts = true.
  • auto-set-music-player = false, default-player empty; cache-directory = cache location + player/; max-cache-size computed (application default 10 GiB); chomikbox1-cache for the 1.x import; connection-retry = 15 s; maximum-volume = 0.7.

Debug and miscellaneous

  • [debug] level = 6, on a scale explained in the file as 0 - none, 1 - most important … 5 - a lot … 9 - garbage, dumps etc.; network-debug = false; upload-connection-test-period = 120.
  • [breakpad] disable-on-exit = true; [guistats] enabled = false. The [guistats] setting does not feed or gate BoxEvents.
  • Developer switches: --h4x0r / --chakier unlock hidden Settings options (no network effect), and --file-server <host> forces the upload and resume-check host, also when it arrives over the single-instance pipe. See Components and C-08. Observed
  • [notifications] toggles: global, file-uploaded, file-downloaded, add-music-file, add-music-files (all true).
  • [tutorial] enabled = false, module-info-show = true, welcome-info-show = true.
  • [future] remove-uploaded-file-in-menu = false, labelled physically deletes files that were uploaded, and upload-downloaded-file-in-menu = false.
  • [linux] autostart-command-timeout = 5: the code base apparently also targeted Linux. Inferred

base.ini - brand bootstrap

[main]
domain = chomikuj.pl
title  = ChomikBox
name   = ChomikBox
key    = <32 hex characters>
domain
Selects :/default/defconf-<domain>.ini and the host names: box.<domain> (SOAP), session.box.<domain>, bts.box.<domain> and download.box.<domain> (updates), plus the balloon skin names.
title
Window title and the name of the data folder %LOCALAPPDATA%\<title>.
name
QCoreApplication::applicationName, also the name of the autostart Run value.
key
An anti-tamper checksum over the [main] section, verified at start-up; it is not used anywhere in the network protocol. On a mismatch the client stops with qFatal("HACKING! base.ini/main corrupted."). Observed
optional
data-location (may use ${app} or ${cwd}), cache-location, app-location.

installer.exe rewrites title and domain only when the system clock is earlier than 2012-01-01, so on any current system it never does. Observed
