Windows integration - registry, shell, IPC

  1. Overview
  2. Windows integration

The MSI registers ChomikBox with the shell: a chomik:// URL protocol, two Explorer context-menu verbs, music ProgIDs, shortcuts and an uninstall entry. The running app adds an autostart value and, if asked, takes over music file associations. Everything that reaches the app from outside ends up in one command parser, delivered over a named pipe or on the command line.

Facts on this page come from read-only queries of the cached MSI tables and the live registry key names, and from the behaviour of the client. Observed unless marked.

Registry - keys written and read

The MSI installs per machine (ALLUSERS=1, every row under HKLM). Because the executables are 32-bit, the keys appear under Wow6432Node on 64-bit Windows where redirection applies. The one exception is the plug-in's start path (below): the updater writes it, and the plug-in reads it, in the 64-bit view. The app's own settings are not in the registry: it uses INI files, and QSettings touches the registry only for the Run value and file associations.

chomik:// - the URL protocol

HKLM\Software\Classes\chomik is a standard URL-protocol registration: a browser or any other program that opens a chomik: URL starts "…\ChomikBox.exe" "%1" with the whole URL as a single argument. If ChomikBox is already running, that new process forwards the URL over the named pipe and exits.

Application::executeRemoteCommand accepts chomik://file:…, chomik://folder:… and chomik://files/…. Web links on the chomikuj.pl domain that contain ShowVideo.aspx?id= or Image.aspx are converted to chomik://files/…; any other http(s) link becomes an external-link download, which opens the agreement window (external-link-agreement). Observed The exact syntax after each prefix is not documented yet. Unknown

After an update, installer.exe rewrites chomik\shell\open\command and chomik\DefaultIcon to point at the new executable.

File associations - music player

The MSI registers a ProgID ChomikBox.MusicFile.<ext> for each of 21 extensions but does not bind any extension to it. Binding happens only when the user makes ChomikBox the default player, or automatically when [player] auto-set-music-player = true (default false).

  • The app writes the UserChoice\Progid value under HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\FileExts\.<ext> with raw RegCreateKeyExW / RegSetValueExW calls, elevating through BProcess::runAsAdministrator or runAsDesktopUser when needed. Observed The ProgID keys it touches go through QSettings, but whether under HKCU or HKLM is not resolved. Inferred
  • The result is remembered in [player] default-player. Dialogs: %1 is now set as default music player on this computer. and, when another program has taken over, %1 is no longer default music player on your computer. Do you want to set %1 as default player again?

Remote commands - named pipe and lock file

Every external trigger reaches the same function in the running instance, Application::executeRemoteCommand. There are two routes. A newly started chomikbox.exe uses QtSingleApplication to find an existing instance and hand over its command line. The browser plug-in does the same by hand: it checks a mutex and writes to the pipe itself.

The objects

  • Lock file %TEMP%\qtsingleapp-Chomik-739b-<sessionId>-lockfile: 0 bytes, locked with QtLockedFile while ChomikBox runs. A leftover file from session 1 was present on the inspected machine. configurator.exe refuses to run while the lock is held.
  • Named pipe \\.\pipe\qtsingleapp-Chomik-739b-<sessionId> (QtLocalPeer): exists only while the app runs. The name comes from qtsingleapp-, the first six letters of the app id ChomikBox2, its CRC-16 739b and the session id.
  • Frame format: QDataStream::writeBytes, a 4-byte big-endian length followed by the bytes. The plug-in sends -d + URL + NUL.
  • Mutexes: ChomikBox2 is probed by the plug-in; ChomikBoxMutex is checked by 2.x to detect a running ChomikBox 1.x.

The full list of switches is on Components. Who may connect to the pipe (its security descriptor) is not known. Unknown

Resolving the data folder

BaseApplication::__init uses base.ini [main] data-location if set (it may contain ${app} or ${cwd}), then --data-location <dir>, and otherwise QDesktopServices::storageLocation, which Qt 4 maps to %LOCALAPPDATA%\<title>. cache-location and app-location in base.ini are honoured too. If the folder cannot be written the app logs data location is not writable.

Credentials on disk

conf.ini stores [userinfo] login, password-hash (the MD5 that the API accepts as the password) and password-len, plus [proxy] username and password, all in plain text. See Security, C-03.

Autostart - the Run value

When autostart is on, the app writes HKCU\Software\Microsoft\Windows\CurrentVersion\Run value ChomikBox (the name is QCoreApplication::applicationName, from base.ini [main] name) holding the native path of chomikbox.exe; it removes the value when autostart is switched off. This is done through QSettings on that key.

The setting is [application] autostart, default true in the default config, and the tray menu item «Uruchom automatycznie po starcie systemu» (Start automatically after system boot). On the inspected machine the user value was false and there was no Run value.

Browser integration - Click Catcher

Under «Integracja z przeglądarkami» (Browser integration), BrowserIntegrationManager finds installed browsers through:

  • HKCU\Software\Opera Software, value Last Install Path;
  • HKLM\Software\Microsoft\Windows\CurrentVersion\App Paths\Chrome.exe and firefox.exe (value Path) and Safari.exe (default value).

Paths are stored in [browser-integration] opera-browser-path, chrome-browser-path, firefox-browser-path and safari-browser-path. If a browser cannot be found the user is asked to Locate browser installation folder. Installation runs installer.exe --plugmode --install tsplugins/integration/ <browser dir> into one of the sub-folders /program/plugins, /plugins or /Plugins, and success sets [downloader] chrome-integrated (or opera-, firefox-, safari-integrated) to true.

The plug-in itself is described on Components. Current browsers no longer load NPAPI plug-ins, so this path is obsolete. Inferred The chomik:// protocol and the Explorer verbs are independent of it. [downloader] external-link-agreement = true shows the agreement window for links that do not point to chomikuj.pl.

Windows 7 taskbar

chomikbox_win7.tsp runs inside the main process. It sets the explicit AppUserModelID fsfilesolutions.chomikbox, adds previous / play-pause / next buttons to the taskbar thumbnail and shows transfer progress on the taskbar button through ITaskbarList3. Details: Components.

Installer footprint - shortcuts and actions

  • Shortcuts: Start menu Chomikuj.pl\ChomikBox and Odinstaluj ChomikBox (uninstall, MsiExec /x{ProductCode}), Desktop ChomikBox, Quick Launch ChomikBox, and Odinstaluj ChomikBox.lnk in the install folder.
  • After install: chomikbox1conf.exe on a fresh install and on a major upgrade (ExeCaKeyF01, condition not Installed, synchronous, started without arguments, so it imports silently only when no 2.x conf.ini exists); it does not run on repair, minor updates or in-app updates Inferred; optional launch from the finish page (CaLaunchProductCheckBox).
  • After uninstall: cmd /c start http://Chomikuj.pl/chomik/chomikbox/AppUninstalled (ExeCaKeyF03, asynchronous).
  • Runtime: MSVC90 CRT side-by-side merge modules.
  • Identity: ProductCode {8E4185CC-4FF3-46B9-A4DB-5B850B71ABC4}, UpgradeCode {76EE0600-FE66-4741-8BD7-EA1EBBCC0430}, ProductLanguage 1045 (Polish).
